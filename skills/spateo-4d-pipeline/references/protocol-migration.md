# Protocol-to-native migration

Reference: [Spateo-protocol-files/code](https://github.com/gmhhhhhh-929/Spateo-protocol-files/tree/b11ae99fbdc4ae46d41880e9306ab7e5c2751ac5/code), commit `b11ae99fbdc4ae46d41880e9306ab7e5c2751ac5`. The reviewed 10→14 dpa notebooks are `04_alignment_and_morphogenesis/03_10dpa_14dpa_model_alignment.ipynb` and `04_10dpa_14dpa_cns_morphogenesis.ipynb`; the 7→10 pair uses the same public workflow. Use stage labels and paths from the user's experiment.

| Reference operation | Maintained implementation / correction |
| --- | --- |
| Load counts, normalize and log | `st.pp.normalize_total` then `st.pp.log1p_layer`. Explicit counts semantics; no Dynamo preprocessing. Preserve counts and normalized expression separately. |
| Cross-stage registration | `st.align.morpho_align_ref` on both full 3D objects. The fourth return is reference transport matrices (`pis_ref`), not sigma values. |
| Visual nonrigid overlay, then rigid mapping | Use one explicit base key controlled by SN-S/SN-N for numerical analysis and its dashboard. Preserve auxiliary keys for intentional review. |
| CNS subset and shared genes | Configurable observed annotation subset, source-order common genes with positive counts in both; normalize again after harmonization. |
| Cell direction | `st.tdr.cell_directions` gives mapped endpoints and displacement plus transport matrix. Save transport with source/target IDs; no claim of tracked cell lineage. |
| Point/surface vector field | `st.tdr.morphofield_sparsevfc` backed by `spateo._native`. Default NX is source coordinates; surface reconstruction is not required for fitting. Mesh-specific plots can evaluate the field at an independently validated mesh. |
| Morphopath | Native integration; model duration is configurable. Notebook 2e4/5e4 horizons depend on vector scaling and must not transfer blindly. Save trajectories before later branches. |
| Differential geometry | Native velocity, acceleration, curl, divergence, torsion and curvature. Export metrics by source cell ID. |
| GLM | Fix literal `"~cr({key}, df=3)"` to an interpolated formula. Use size-factor-normalized counts rather than notebook `.X` after log1p. Preserve warnings/failures and save result CSVs. Thresholds are configuration, not copied specimen constants. |
| Gene GP | Keep `st.tdr.gp_interpolation`; provide verified genes and native Torch/GPyTorch dependencies. Save interpolated AnnData, which the notebook primarily plotted. |
| Cameras, z-offsets, huge arrow factors | Display-only choices; no coordinate edits. Interactive dashboard vectors use a display scale. |
| Paths and notebook state | Replace absolute lab paths, duplicated mutable variables and manual writes with config, independent checkpoints, logs and hashes. |

This is a reusable native migration, not a claim of numerically identical notebook results. Default normalization targets, fit parameters, finite integration horizon and optional plotting differ deliberately and are recorded. The protocol source already uses some Spateo-native preprocessing; the old local skills still contained obsolete environment instructions. No package downgrade or Dynamo installation is needed.

The 3D pipeline now implements point-cloud construction and VTK round-trip validation. Surface/voxel/cell reconstruction, anatomical backbone workflows, and the separate myotome interpolation notebook remain pending future 3D phases. The 4D pipeline's optional expression GP is the morphogenesis-related operation already present in the reference. Static mesh/trajectory publication plots are optional manual extensions, not silently reported as generated by the dashboard.

Exact reviewed source and notebook hashes are recorded in [source_manifest.json](source_manifest.json).
