# Protocol and current native implementation audit

Audited 2026-09-24 against [gmhhhhhh-929/spateo-release](https://github.com/gmhhhhhh-929/spateo-release/tree/615644f88613bea8ceb2e2df1e2391d16de55ec1), commit `615644f88613bea8ceb2e2df1e2391d16de55ec1`, and the [7dpa→10dpa CNS protocol](https://github.com/gmhhhhhh-929/Spateo-protocol-files/blob/main/code/04_alignment_and_morphogenesis/02_7dpa_10dpa_cns_morphogenesis.ipynb). Feature coverage also follows the [morphogenesis feature tutorial](https://spateo-release.readthedocs.io/en/latest/tutorials/notebooks/7_morphogenesis/3_morphogenesis_feature.html). The tutorial includes Jacobian, which is a tensor rather than a directly usable scalar GLM predictor.

| Operation | Current implementation and practical implication |
| --- | --- |
| Dependencies | No Dynamo import: sampling, field estimation, integration and geometry are in `spateo._native`. Package names alone do not establish backend equivalence; record hashes. |
| Cell mapping | `cell_directions` selects target cells from an FGW transport plan (ties use spatial relation), then returns endpoint minus source XYZ. Do not call it a barycentric mean, registration transform or true cell lineage. |
| SparseVFC API | The maintained wrapper uses native Gaussian RBF controls, ridge regularization and Huber-style IRLS (`_native/vectorfield.py`). It is not numerically identical to historical Dynamo SparseVFC. Kernel bandwidth defaults to reciprocal twice median squared control-point distance. |
| Iterations | Native keyword is lowercase `max_iter=8`, plus `tol`. Legacy `MaxIter=500` enters ignored kwargs, as can obsolete solver controls. Strict v4 configuration rejects MaxIter. |
| Fitted magnitude | The native estimator fits raw displacement in input coordinate units without hidden unit-vector rescaling. Ridge strength, control coverage and beta can shrink/smooth magnitudes. Save raw and fitted q50/q95, directional cosine and RMSE. No fixed historical-to-native conversion factor exists. |
| Arrow rendering | VTK glyph factor scales geometry. `construct_field(...arrows_scale_key='vectors')` uses vector magnitude; the protocol now estimates factor from model extent and q95. Fixed 1e4/1e5 factors are not transferable. The interactive viewer uses a disclosed relative factor and real arrowheads; it never rescales stored fields. |
| Trajectory | Native `solve_ivp` integrates the field from source seeds; audited morphopath stores each prediction as time × XYZ. `cores` does not enable parallel integration in this native implementation. Default t_end=1 is explicit model time, not one day; historical 5e4 can yield long extrapolation. Review bounds, endpoint displacement and duration rather than copying horizons. |
| Acceleration/curvature | Acceleration is Jv; curvature uses the normal acceleration relation. These are field-derived features at source states, not finite differences of sparse trajectory samples. |
| Curl/divergence | Curl vector is stored with scalar magnitude in 3D; divergence is signed Jacobian trace. Explicit velocity/Jacobian components retain signs. |
| Torsion | Native code uses `(v×a)·(J a)/|v×a|²` along the normalized binormal, then the wrapper stores its magnitude. This omits the full derivative-of-J term of general jerk. Treat it as this implementation's torsion proxy, not signed classical torsion or an unchanged Dynamo result. |
| Jacobian | Native analytical 3×3×cells tensor; preserve tensor and IDs. Components and Frobenius norm are separately named scalar choices for plotting/GLM. |
| GLM | Use size-factor normalized, unlogged expression; fix the notebook's literal `~cr({key}, df=3)` to interpolation. Spateo NB2 uses alpha=1. Failed genes disappear from its result table, so restore their status in the external test ledger. Use all returned p/q-values and a separate significance flag. Returned p/q-values are cast to float32, so stored zeros may reflect numerical underflow; do not report them as exact zero probabilities. Preserve actual mu and intervals for plotting. |
| Mesh | Native fields can be evaluated directly at source points; a mesh is optional. When needed, use the 3D reconstruction subskill on aligned point clouds rather than reintroducing large notebook smoothing defaults. |

This audit establishes source behavior, not a paired numerical benchmark against an installed historical Dynamo release. Biological calibration, registration accuracy and association robustness require independent assessment. Do not advertise native results as numerically reproduced historical notebook outputs.
