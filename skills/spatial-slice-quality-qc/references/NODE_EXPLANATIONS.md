# Spateo Referee：逐节点输入、操作与输出说明

本说明覆盖完整流程图的60个处理/判断节点，以及1个滑动窗口示意控件，共61项。编号与[带编号SVG](spateo_referee_annotated.svg)及[可点击对照页面](workflow_explained.html)一致；原始未编号SVG保留不动。

## 先明确图中流动的是什么

A输出原始测量和输入来源；B为每片确定比较对象；C把每个测量的偏离程度转为异常证据；D聚合为四域和总分；E产生最终keep/exclude；F把证据、坐标和决策组织为报告。大区箭头表示这些信息的依赖，不表示每一区只执行一次：C会被B的主/支持窗口调用，第二阶段确认窗口也会重复相应评分。

图中的矩形一般表示处理或数据结果，菱形表示选择/判断；A的可用信号是并行分流，非互斥三选一。实线表示信息流或判断后的去向；带yes/no、all pass/any fails的线表示条件成立/失败；D的虚线是规则定义指向判断，不是额外处理。跨区C/D圆标只是续接位置，没有计算功能。浅绿色keep与红色exclude才是公开动作，其余颜色帮助分组，不是独立阈值。

## 常用词与符号

| 名称 | 此处含义 |
|---|---|
| 点 / spot / cell | 数据的一行空间观测，可能是细胞或测量spot，依数据平台而定 |
| H5AD / obs / obsm | 数据文件 / 逐点元数据表 / 坐标等逐点数组 |
| i / W | 当前切片索引 / 含当前片在内的窗口总宽度 |
| v / e | 当前片的原始指标值 / 邻居估计的同一指标局部期望 |
| m / mild / severe | 不利变化效应量 / 单指标轻、重效应界限 |
| R / z / Z / A | 效应证据 / 稳健标准化残差 / 映射到0–1的残差证据 / 合并后的单指标异常 |
| D / X / M / C | 密度、表达、损伤代理、连续性四个域分数；域X不是AnnData.X |
| S₀ / S | 未保护的综合分数 / 保护与端点处理后的最终异常总分 |
| supporting domain | 域分数≥.45，属于支持异常的域；不意味着统计独立 |
| clip(x,0,1) | 将x限制在0到1之间；低于0设0，高于1设1 |
| MAD / SD | 绝对偏差中位数 / 标准差，用于刻画波动尺度 |
| profile / pseudobulk | 将一个切片内点的基因表达汇总形成表达概貌 |
| KDE / NN | 核密度估计 / 最近邻；是空间测量或展示，不是最终质量概率 |
| confidence | 当前邻域支持字段，主要取1或.72，不是正确率概率 |
| tier / AND | 某分数区间采用的一套门控 / 列出的条件必须全部成立 |
| T / H / frame_id | 原始到共同参考的变换 / 相邻片变换 / 展示坐标系唯一标识 |

同样的0.65可能出现在不同公式中：域内top-two的0.65是权重，低分细筛的0.65是最强域门槛。它们不能混用。最终分流.129/.540/.700也不是单指标mild/severe。

## 一条示例贯穿流程（仅用于说明，并非新增实验）

假设一张内部切片有可靠计数和双侧邻居。某指标期望计数1000、当前400，则相对下降m=.60；计数效应映射R约.946，但这仍要结合残差、上下文和其他证据，不能直接当最终总分。若最终四域为D=.65、X=.55、M=.10、C=.20，则S₀=.464；没有保护且双侧时S=.464。第一阶段进review，第二阶段选低分tier，要求2个域≥.45、最强域≥.65及所有其他门控。主窗口和全部可用确认窗口均通过才exclude；任一必要窗口失败则keep。示例没有指定真实切片，也不构成性能结果。


## A区：输入与信号选择

### A01 · 输入数据采用什么组织方式

图中文字：**Input format**

**输入：**原始H5AD文件或一个包含多个H5AD的目录；H5AD通常保存每点表达、点的元数据以及空间坐标。

**具体操作：**先确定文件里有哪些生物样本、每个点属于哪张切片，再选择相应的切片识别方式。不同样本各自建序列，不把多个发育时期接成一条序列。

**输出：**待解析的文件列表和数据集边界；此时还没有质量分数。

**后续去向：**按数据组织方式进入A02「使用现成的切片标签」、A03「由离散z值识别切片」或A04「每张切片一个文件」。

**例子：**7dpa1和10dpa1分别计算，不能让7dpa1最后一张的邻居变成10dpa1第一张。

实现追溯：`scan_h5ad_series; scan_h5ad_collection`；SVG节点ID：`a_input`。

### A02 · 使用现成的切片标签

图中文字：**Slice labels**

**输入：**一个H5AD及指定的obs切片字段，例如每个点的slice_id。obs是一行对应一个点的元数据表。

**具体操作：**按字段值把点分成切片，并按指定顺序或解析出的顺序排列。

**输出：**每个点的切片归属、唯一切片ID列表和切片顺序。

**后续去向：**进入A05「确认切片顺序、原始坐标和来源」，核对排序与坐标。

**例子：**同一文件中slice_id为SL01的所有点组成SL01切片。

**容易误解的地方：**标签名称本身不一定表示真实物理顺序。

实现追溯：`_resolve_slice_labels; _resolve_order`；SVG节点ID：`a_Slice_labels`。

### A03 · 由离散z值识别切片

图中文字：**Discrete z**

**输入：**带离散第三坐标z的空间数组；每个切片内的z应能形成明确的层。

**具体操作：**按z层分组并形成z标签，同时保留实际z和原始x/y。

**输出：**点到z切片的映射、z切片ID与顺序；x/y继续用于二维QC。

**后续去向：**进入A05「确认切片顺序、原始坐标和来源」。

**例子：**z=80这一层可显示为z80；z不进入二维密度面积计算。

**容易误解的地方：**连续散布的三维细胞不能未经核对就假定为离散切片。

实现追溯：`_resolve_slice_labels; _resolve_order`；SVG节点ID：`a_Discrete_z`。

### A04 · 每张切片一个文件

图中文字：**One file / slice**

**输入：**一组切片H5AD路径，以及可选的path/order清单。

**具体操作：**默认按自然文件名顺序排列；若文件名顺序不符合实际切片顺序，使用清单指定。

**输出：**有序文件/切片列表，每片保留来源文件。

**后续去向：**进入A05「确认切片顺序、原始坐标和来源」。

**例子：**自然排序将SL2放在SL10前；普通字典序可能相反。

实现追溯：`_resolve_slice_labels; _resolve_order`；SVG节点ID：`a_One_file__slice`。

### A05 · 确认切片顺序、原始坐标和来源

图中文字：**Resolve slice order + original x/y**

**输入：**上游解析的切片归属、排序、坐标候选键、表达层与元数据。

**具体操作：**确认实际选用的原始x/y、顺序和表达层；记录单位信息、点身份和源文件校验值。未知单位应标为未知，不能凭图形大小猜单位。

**输出：**可追溯的输入契约：每个点是谁、在哪张切片、使用哪套坐标和表达值。

**后续去向：**必需字段解析失败→A06「停止当前受阻的数据集」；通过→A07「检查有哪些可用信号」。

**例子：**spatial与spatial_artificial_unaligned是不同坐标键，不能任意替换。

**容易误解的地方：**此节点不执行配准，也不改变原始数据。

实现追溯：`_resolve_xy; _resolve_order; _extract_one_file`；SVG节点ID：`a_contract`。

### A06 · 停止当前受阻的数据集

图中文字：**Stop affected run**

**输入：**必需字段、坐标或切片身份无法可靠解析的错误。

**具体操作：**记录失败并停止依赖这些信息的当前运行。其他独立数据集是否继续由批处理入口处理。

**输出：**错误/失败状态；没有可供解释的有效QC分数。

**后续去向：**先修正输入契约，再从A01「输入数据采用什么组织方式」开始。

**例子：**无法确定哪列代表切片时，不把每个细胞当作一张切片。

实现追溯：`_extract_one_file`；SVG节点ID：`a_stop`。

### A07 · 检查有哪些可用信号

图中文字：**Which signals**

**输入：**已确认契约的坐标、表达矩阵和可选细胞类型标签。

**具体操作：**分别检查几何、矩阵、注释三类信号。这里是可并行的可用性分流，不是三选一。

**输出：**可用信号清单及各自处理路径。

**后续去向：**坐标→A08「从坐标计算组织几何」；表达矩阵→A10「判断所选矩阵的语义」；注释→A09「从细胞类型标签提取组成信号」。

**例子：**只有可靠坐标也能计算几何证据，但不能凭空生成表达捕获证据。

实现追溯：`_extract_one_file`；SVG节点ID：`a_signals`。

### A08 · 从坐标计算组织几何

图中文字：**Spatial geometry**

**输入：**每片原始x/y；若可用，局部低捕获指标还需要该点的捕获计数。

**具体操作：**用有限坐标计算凸包面积、点密度、最近邻间距及尾部、连通成分、碎片、空洞等。退化点集按函数规则返回受限值。

**输出：**每片一组几何指标，而非图像是否“漂亮”的判断。

**后续去向：**汇入A14「生成逐片指标和可用性记录」，随后用于B/C及D中的密度、损伤和连续性域。

**例子：**最大连通成分占比0.9表示90%的有效几何点属于同一最大连通组织成分。

**容易误解的地方：**QC几何中的min_points_geometry=20未实际生效；展示配准中的最小20点是另一条真实规则。

实现追溯：`_geometry_metrics: n<2 returns NaN geometry and conservative defaults; invalid x/y excluded from geometry`；SVG节点ID：`a_geometry`。

### A09 · 从细胞类型标签提取组成信号

图中文字：**Cell-type labels**

**输入：**真实存在且被选用的细胞类型/注释字段，逐点对应。

**具体操作：**统计每片各类型的数量和比例，后续比较相邻切片的组成分布；没有标签则不产生该证据。

**输出：**每片的类型比例向量；不是基因表达矩阵。

**后续去向：**汇入A14「生成逐片指标和可用性记录」，并参与D04「跨切片连续性证据域C」；标签还可在显式配置时用于展示配准候选排序。

**例子：**一片神经细胞20%、肌肉细胞80%是一组组成比例。

**容易误解的地方：**类型比例改变既可能来自技术缺陷，也可能来自真实解剖变化。

实现追溯：`_celltype_js_profiles; _extract_one_file`；SVG节点ID：`a_labels`。

### A10 · 判断所选矩阵的语义

图中文字：**Selected matrix**

**输入：**选定的表达层/AnnData.X、计数形态检查、元数据及声明的表示类型。

**具体操作：**区分计数矩阵、非计数矩阵，以及契约明确声明的注释one-hot X。one-hot即每点以0/1表示所属类别，不是测得的基因计数。

**输出：**决定允许从矩阵中提取哪些表达/捕获量。

**后续去向：**计数→A11「处理测得的计数矩阵」；非计数→A12「处理归一化等非计数矩阵」；声明的one-hot X→A13「处理声明的注释one-hot X」。

**例子：**每行只有一个1的类型编码，行和总是1，不能据此说每个细胞都捕获了1个转录本。

**容易误解的地方：**数值看起来像整数只是线索，不等于生物学计数语义已确认。

实现追溯：`_choose_layer; _is_count_like; blind_input_contract.expression_representation`；SVG节点ID：`a_matrix_type`。

### A11 · 处理测得的计数矩阵

图中文字：**Measured counts**

**输入：**每行一个点、每列一个基因的非负计数层。

**具体操作：**逐点求行和作为捕获计数，求非零基因数；按切片汇总。所选计数层的实际值优先于过时obs汇总。

**输出：**每点计数/基因数、切片捕获指标及可用于连续性计算的表达汇总。

**后续去向：**汇入A14「生成逐片指标和可用性记录」。

**例子：**一行[2,0,5]给出总计数7、检出基因2。

**容易误解的地方：**捕获计数不等于原始测序reads，也不直接反映测序饱和度。

实现追溯：`_extract_one_file; _align_profiles`；SVG节点ID：`a_semantic_20`。

### A12 · 处理归一化等非计数矩阵

图中文字：**Non-count matrix**

**输入：**非计数表达矩阵，以及可能存在的obs原始计数/基因数汇总。

**具体操作：**当前实现优先使用obs计数/基因数；若无obs则使用矩阵行和/非零数作为代理量，并保留语义限制。表达profile仍可进入连续性处理。

**输出：**注明来源的汇总或代理量；不能无条件解释为真实捕获深度。

**后续去向：**汇入A14「生成逐片指标和可用性记录」。

**例子：**log-normalized矩阵的行和不是UMI总量；若obs保存了可靠total_counts，应识别并使用该来源。

**容易误解的地方：**图画的是当前实际行为；没有表示非计数输入已得到与原始计数等价的验证。

实现追溯：`_extract_one_file; _align_profiles`；SVG节点ID：`a_semantic_425`。

### A13 · 处理声明的注释one-hot X

图中文字：**Declared one-hot X**

**输入：**所选矩阵为X，且输入契约明确声明expression_representation包含one-hot。

**具体操作：**将捕获、相关表达统计和线粒体代理设为不可用，并跳过表达pseudobulk；保留原始几何和实际注释信息。

**输出：**几何/注释可用，表达捕获不可用的指标记录。

**后续去向：**汇入A14「生成逐片指标和可用性记录」。

**例子：**每个点的one-hot类别向量不会被用来推断该点是否低表达。

**容易误解的地方：**需要可靠声明；未声明的one-hot矩阵不能假定实现必然识别。

实现追溯：`_extract_one_file; _align_profiles`；SVG节点ID：`a_semantic_830`。

### A14 · 生成逐片指标和可用性记录

图中文字：**Per-slice metrics + availability + provenance**

**输入：**几何、表达和类型分支的结果，以及来源契约。

**具体操作：**以切片为单位合并，保留每项指标的原始值、可用性和输入警告。

**输出：**一张每行对应一片的指标表，以及表达profile/类型向量、点抽样和来源记录等配套对象。

**后续去向：**送入B进行邻域比较；每项测量在C转为异常证据。

**例子：**median_total_counts是一片中所有点总计数的中位数，不是已经标准化的异常分数。

实现追溯：`_extract_one_file`；SVG节点ID：`a_output`。

## B区：窗口与边界

### B01 · 决定使用固定窗口还是自动选窗

图中文字：**Window mode?**

**输入：**有序切片指标，以及用户配置的window。

**具体操作：**固定数字直接指定主窗口宽度；auto比较候选宽度。宽度包含当前片本身。

**输出：**将采用的选窗方式。

**后续去向：**固定→B02「使用固定主窗口」；auto→B03「自动比较候选窗口」。

**例子：**W=3表示前一片、当前片、后一片，共3片。

**容易误解的地方：**自动选窗不表示.129/.540/.700这些最终阈值也会按数据集自动改变。

实现追溯：`SliceQCConfig; _choose_window`；SVG节点ID：`b_window_mode`。

### B02 · 使用固定主窗口

图中文字：**Fixed window**

**输入：**指定的奇数窗口宽度W，默认3。

**具体操作：**保留该宽度，不进行候选窗口效用比较；靠近边界时只用实际存在的邻居。

**输出：**主窗口宽度W及记录。

**后续去向：**进入B04「滑动窗口示意中的切片、虚线框与箭头」，再按B05「逐指标检查有效邻居位于哪一侧」处理每片每指标。

**例子：**第一张切片的W=3窗口只有自己和后一片，不虚构前一片。

实现追溯：`_choose_window`；SVG节点ID：`b_fixed`。

### B03 · 自动比较候选窗口

图中文字：**Automatic choice**

**输入：**整组原始指标和候选3/5/7，候选必须不超过系列长度。

**具体操作：**对每个候选宽度，最多选择8个确定性位置施加有限的表达指标扰动，计算检出、得分增量和基线非keep比例，并对较大窗口加惩罚。按记录的效用选择。

**输出：**一个主窗口宽度及各候选效用记录。没有可用候选时回退W=3并注明系列过短。

**后续去向：**进入B04「滑动窗口示意中的切片、虚线框与箭头」。

**例子：**效用=扰动检出比例+0.35×平均分数增量−0.35×基线非keep比例−0.012×(W−3)。

**容易误解的地方：**这是选窗启发式，不是独立准确率评估；这里最多8个位置不是8组数据或8轮正式验证。

实现追溯：`_choose_window: utility=recall+.35*delta-.35*baseline_flags-.012*(W-3); no candidate -> W=3`；SVG节点ID：`b_auto`。

### B04 · 滑动窗口示意中的切片、虚线框与箭头

图中文字：**Move the focal index i through the ordered series**

**输入：**按切片索引排序的系列，以及主窗口W。

**具体操作：**紫色i是当前片，虚线框是当前窗口；计算参照时排除i，只取框内有效邻居。随后i前进一位，重新为下一张切片计算。

**输出：**每张切片自己的邻居集合；没有一个固定的全局“正常切片”充当所有参照。

**后续去向：**进入B05「逐指标检查有效邻居位于哪一侧」。

**例子：**图中W=5时，i的候选邻居是i−2、i−1、i+1、i+2；最外侧省略号不是具体数据点。

**容易误解的地方：**这里是切片顺序窗口，不是空间坐标里的ROI框，也不是跨物种窗口。

实现追溯：`_local_expected; _choose_window`；SVG节点ID：`b_sliding_window_example`。

### B05 · 逐指标检查有效邻居位于哪一侧

图中文字：**Finite neighbors for this metric?**

**输入：**当前片、候选邻居，以及某一指标的有限数值。

**具体操作：**分别查看当前片前后是否有有效值。同一切片不同指标可能因缺失情况不同而走不同分支。

**输出：**双侧、仅单侧或无有效邻居的状态。

**后续去向：**双侧→B06「用双侧邻居估计局部期望」；单侧→B07「用单侧邻居估计期望」；无邻居→B08「没有可用参照」。

**例子：**两侧切片都存在，但前一片的计数指标缺失时，该计数指标可能只能使用后一侧。

实现追溯：`_local_expected: finite neighbors within truncated window`；SVG节点ID：`b_context`。

### B06 · 用双侧邻居估计局部期望

图中文字：**Both sides**

**输入：**当前片前后都有该指标的有效值。

**具体操作：**排除当前片，对邻居数值按位置拟合中位两两斜率趋势，再在当前索引处求期望；同时记录左右中位数差异。

**输出：**局部期望e、双侧标记及左右不一致程度。

**后续去向：**在B09「合并主窗口与稳健支持窗口的证据」安排主/支持窗口计算，再送C标准化。

**例子：**若前后正常计数分别约900和1100，当前片的期望可能约1000；不把当前片自身低计数混入参照。

实现追溯：`_local_expected; _metric_anomaly`；SVG节点ID：`b_context_25`。

### B07 · 用单侧邻居估计期望

图中文字：**One side only**

**输入：**端点或缺失后，只剩当前片一侧的有效邻居。

**具体操作：**使用这些邻居的中位数；窗口在边界截断，不循环到序列另一端，也不补造切片。

**输出：**单侧期望e和单侧标记；后续指标证据与总分受到边界减权。

**后续去向：**继续B09「合并主窗口与稳健支持窗口的证据」/C；最终E不能仅靠单侧证据自动排除。

**例子：**第一张切片只有后方邻居；不是因为缺少前方切片就认定它质量差。

实现追溯：`_local_expected; _metric_anomaly`；SVG节点ID：`b_context_425`。

### B08 · 没有可用参照

图中文字：**No valid neighbor**

**输入：**窗口内该指标没有任何有效邻居。

**具体操作：**期望保留为不可用，该指标内部异常值为0；不补值，也不制造可比较性。

**输出：**无参照的记录和“未获得异常证据”的内部值。

**后续去向：**继续合并其他可用指标；该项不能作为排除依据。

**例子：**所有邻居都没有表达测量时，不能用“表达异常=0”推断当前片表达正常。

实现追溯：`_local_expected; _metric_anomaly`；SVG节点ID：`b_context_825`。

### B09 · 合并主窗口与稳健支持窗口的证据

图中文字：**Primary + robust support window**

**输入：**主窗口结果，以及同组数据可支持的较宽趋势窗口。

**具体操作：**分别重算指标异常，并保留两者较大值。常用配置下支持宽度最多9；实际公式会保证不小于主窗口。主窗口的双侧信息继续用于切片上下文。

**输出：**最终单指标异常、两套期望/证据记录，以及切片上下文与score_confidence。

**后续去向：**C描述这里使用的单指标算法；合并后的证据进入D。

**例子：**连续几张低质量片可能互相掩盖；较宽支持趋势提供另一组参照。

**容易误解的地方：**B→C是说明分工：实现会在主窗口和支持窗口分别调用C，再取max，不是只计算一次C。切片双侧字段为各评分指标双侧状态取any；confidence为1或.72，不是正确概率。

实现追溯：`_score_metrics: support=max(W, max(3, min(9, largest odd <=N))); internal=np.any(two_sided_matrix)`；SVG节点ID：`b_support`。

## C区：单指标标准化

### C01 · 准备当前观测与局部期望

图中文字：**Observed value v + local expectation e**

**输入：**原始指标值v，以及B估计的同一指标期望e。

**具体操作：**确保比较的是同一测量、同一单位；检查有限值。

**输出：**待计算的差值、方向和可比较状态。

**后续去向：**进入C02「选择异常的方向」。

**例子：**v=400、e=1000可表示当前与期望的每点计数中位数；它们都还不是异常分数。

实现追溯：`_metric_anomaly`；SVG节点ID：`c_input`。

### C02 · 选择异常的方向

图中文字：**Adverse direction?**

**输入：**当前指标名称及预定义的下降型/上升型规则。

**具体操作：**按照指标含义选择“减少不利”还是“增加不利”；方向不是看这次数据升降后临时决定。

**输出：**相应的方向性效应计算方式。

**后续去向：**下降型→C03「计算下降型相对效应」；上升型→C04「计算上升型绝对效应」。

**例子：**计数下降可提示捕获损失；空洞比例上升可提示组织内部缺失。

实现追溯：`_LOW_BAD_RULES; _HIGH_BAD_RULES`；SVG节点ID：`c_direction`。

### C03 · 计算下降型相对效应

图中文字：**Lower is worse**

**输入：**下降型指标的观测v和期望e。

**具体操作：**m=max((e−v)/|e|,0)，分母用极小正数保护。只给不利下降记正效应。

**输出：**相对下降幅度m，以及供稳健残差使用的e−v。

**后续去向：**同时进入C05「把效应大小映射到0–1」与C06「计算稳健残差异常」。

**例子：**e=1000、v=400，则m=.60；v=1200时这一路m=0。

**容易误解的地方：**这不是把全部指标都除以最大值进行min-max归一化。

实现追溯：`_LOW_BAD_RULES; EPS prevents zero division`；SVG节点ID：`c_low`。

### C04 · 计算上升型绝对效应

图中文字：**Higher is worse**

**输入：**上升型指标的观测v和期望e。

**具体操作：**m=max(v−e,0)。比例型指标接近0时，使用绝对增量避免相对倍数爆炸。

**输出：**绝对增加量m，以及供稳健残差使用的v−e。

**后续去向：**同时进入C05「把效应大小映射到0–1」与C06「计算稳健残差异常」。

**例子：**空洞比例由.02升为.08，m=.06（6个百分点），不是异常分数等于3或4。

实现追溯：`_HIGH_BAD_RULES`；SVG节点ID：`c_high`。

### C05 · 把效应大小映射到0–1

图中文字：**Effect-size score R**

**输入：**效应m，以及该指标预设的mild、severe两个效应界限。

**具体操作：**R=clip((m−mild)/(severe−mild),0,1)。clip表示小于0设0、大于1设1。

**输出：**效应证据R；并非最终总分。

**后续去向：**与C06「计算稳健残差异常」的结果在C08「合并证据并降低不可靠邻域的权重」合并。

**例子：**计数的mild=.25、severe=.62；相对下降.60对应R约.946。

**容易误解的地方：**这里mild/severe是单指标效应界限，与第一阶段.129/.700及域阈值.65/.60不同。

实现追溯：`_metric_anomaly; _LOW_BAD_RULES; _HIGH_BAD_RULES`；SVG节点ID：`c_effect`。

### C06 · 计算稳健残差异常

图中文字：**Robust residual score Z**

**输入：**整个序列中该指标的方向性残差，以及当前片残差。

**具体操作：**用残差中位数居中，以1.4826×MAD估计尺度，退化时用标准差，再退化为1。正向标准化残差z映射为Z=clip((z−1.5)/3,0,1)。

**输出：**当前变化相对整组残差分布有多突出，形成证据Z。

**后续去向：**上升型先经C07「限制近零指标被夸大的异常」；下降型直接进入C08「合并证据并降低不可靠邻域的权重」。

**例子：**两个指标有相同绝对变化，但平时波动尺度不同，稳健残差证据可以不同。

**容易误解的地方：**MAD是“绝对偏差的中位数”；这不是检验p值，也不是以当前片自己的点分布估计缺陷概率。

实现追溯：`_robust_scale:1.4826*MAD; fallback std then1; _metric_anomaly`；SVG节点ID：`c_z`。

### C07 · 限制近零指标被夸大的异常

图中文字：**High-direction safeguard**

**输入：**上升型的Z、绝对效应m及轻效应界限mild。

**具体操作：**把Z乘clip(m/mild,0,1)。当绝对变化很小时，即使残差标准化值大，也不给它满额证据。

**输出：**经过最小效应约束的上升型Z。

**后续去向：**进入C08「合并证据并降低不可靠邻域的权重」；下降型旁路跳过本节点。

**例子：**m=.004、mild=.04，则最多保留原Z的10%。

**容易误解的地方：**只作用于上升型稳健残差分支，不同时缩小R。

实现追溯：`_metric_anomaly: only direction=high`；SVG节点ID：`c_small_high`。

### C08 · 合并证据并降低不可靠邻域的权重

图中文字：**Combine, downweight and retain provenance**

**输入：**R、处理后的Z、双侧/单侧状态，以及左右邻居的不一致程度。

**具体操作：**先取max(R,Z)，再乘上下文因子（双侧1、单侧.72）和邻居一致性惩罚（.35–1）。计数/基因另外保留直接相对下降证据；主/支持窗口结果再取max。

**输出：**每项指标的异常A及其期望、支持和缺失信息，供四域聚合使用。

**后续去向：**跨区进入D01「密度与组织量证据域D」、D02「表达捕获证据域X」、D03「损伤代理证据域M」和D04「跨切片连续性证据域C」。

**例子：**若R=.4、Z=.8、双侧且一致性惩罚=.5，则这一路A=.4；计数直接效应或较宽窗口可能再提高最终单指标证据。

**容易误解的地方：**表达profile与类型组成有专用散度映射，不能直接把本节点这条通用式套到所有连续性信号。

实现追溯：`_metric_anomaly; invalid observation/reference gives zero anomaly evidence`；SVG节点ID：`c_merge`。

## D区：域聚合与保护

### D01 · 密度与组织量证据域D

图中文字：**Density / amount D**

**输入：**来自C的密度、点数、空洞、近邻尾部、碎片及最大成分占比异常分数。

**具体操作：**按图中权重聚合，并与最强两个指标的组合取较大值。这样既看总体，也避免少数强信号被均值稀释。

**输出：**0–1的密度/组织量域分数D。

**后续去向：**通过D05「四域共享的域内聚合规则」所示共同规则，进入D06「从四个域得到未保护总分S₀」。

**例子：**输入的“密度异常=.8”已是标准化分数，不再是每平方微米的细胞数。

**容易误解的地方：**这一域共享了碎片、空洞等信号，因此不能把它和损伤/连续性视作完全独立的证据。

实现追溯：`_score_metrics: density_domain_score`；SVG节点ID：`d_domain_Density`。

### D02 · 表达捕获证据域X

图中文字：**Expression capture X**

**输入：**计数、基因、零值比例、复杂度、检出基因比例、局部/区域低捕获的异常分数。

**具体操作：**计算可用指标的加权均值，与最强两个指标组合取较大值。

**输出：**0–1的表达捕获域分数X。

**后续去向：**进入D06「从四个域得到未保护总分S₀」及解剖保护/检测器规则。

**例子：**计数和检出基因同时明显降低，可以共同支持这个域。

**容易误解的地方：**图中的X是一个标量域分数，不是原始表达矩阵AnnData.X。

实现追溯：`_score_metrics: expression_domain_score`；SVG节点ID：`d_domain_Expression`。

### D03 · 损伤代理证据域M

图中文字：**Damage proxies M**

**输入：**线粒体比例异常和组织碎片异常。

**具体操作：**对可用异常分别赋权.65、.35并聚合。

**输出：**0–1的损伤代理域分数M。

**后续去向：**进入D06「从四个域得到未保护总分S₀」和解剖保护规则。

**例子：**线粒体比例异常可能支持应激/损伤，但单靠这个指标不能确认具体实验原因。

**容易误解的地方：**这是损伤代理，不是组织损伤的直接诊断。

实现追溯：`_score_metrics: damage_domain_score`；SVG节点ID：`d_domain_Damage`。

### D04 · 跨切片连续性证据域C

图中文字：**Continuity C**

**输入：**表达profile异常、细胞类型组成异常，以及空洞异常。

**具体操作：**表达profile先比较当前片与邻居平均profile的余弦差异，并考虑左右邻居相似度；类型组成用Jensen–Shannon散度。映射成异常后按.58/.22/.20聚合。

**输出：**0–1的连续性域分数C。

**后续去向：**进入D06「从四个域得到未保护总分S₀」和解剖保护规则。

**例子：**若当前片表达概貌突变，而前后两侧彼此相似，该片可能获得连续性异常证据。

**容易误解的地方：**profile是按片汇总的基因表达概貌；此处并未用展示预配准坐标计算逐点解剖对应。

实现追溯：`_profile_continuity; _celltype_js_profiles; _score_metrics`；SVG节点ID：`d_domain_Continuity`。

### D05 · 四域共享的域内聚合规则

图中文字：**Within-domain rules**

**输入：**某一域中的指标异常分数及固定权重。

**具体操作：**可用有限值做加权均值并按可用权重归一；密度/表达域另算.65×最强+.35×次强，再与均值取max。

**输出：**各域分数的计算规则，不是额外第五个评分域。

**后续去向：**得到四个域分数后进入D06「从四个域得到未保护总分S₀」。

**例子：**最强=.8、次强=.6时，top-two=.73。若该域加权均值=.5，则密度/表达域采用.73。

**容易误解的地方：**上游有些不可用信息被内部记为0证据；0不等于观察到正常。“finite可用值”是实现规则，不能据此补出生物学测量。

实现追溯：`_weighted_available; _top_two_evidence`；SVG节点ID：`d_available`。

### D06 · 从四个域得到未保护总分S₀

图中文字：**Aggregate anomaly score S₀**

**输入：**D、X、M、C四个域分数。

**具体操作：**计算.31D+.39X+.12M+.18C，同时计算最大域支路clip(.48+.78×(最大域−.68),0,1)，两者取max；统计有多少域≥.45。

**输出：**未施加解剖保护和端点减权的总分S₀、支持域数及各域值。

**后续去向：**进入D07「是否触发解剖保护」；总分还不是最终公开动作。

**例子：**D=.65、X=.55、M=.10、C=.20时，加权值=.464，最大域支路=.4566，故S₀=.464。

**容易误解的地方：**S₀不是四个域简单平均，也不是概率；最大域支路解释了为何只降低review分界可能并无效果。

实现追溯：`_score_metrics: raw_score; corroborating_domains`；SVG节点ID：`d_rawscore`。

### D07 · 是否触发解剖保护

图中文字：**Anatomical protection?**

**输入：**四域分数及点数、密度、空洞的单指标异常。

**具体操作：**检查D08「解剖保护条件定义框」列出的两种组合，任一成立就设置保护标记。此处想减少把自然收窄或局部结构差异误当技术缺陷的风险。

**输出：**保护标记true/false。

**后续去向：**yes→D09「对受保护切片限制自动排除」；no→直接将S₀送D10「施加末端减权并交出最终异常分数」。

**例子：**组织量减少，但密度、表达和空洞仍相对正常时，可能符合自然收窄保护。

**容易误解的地方：**保护是经验规则，不是已经确认该组织变化一定合理。

实现追溯：`_score_metrics: density_only OR taper_like`；SVG节点ID：`d_protection`。

### D08 · 解剖保护条件定义框

图中文字：**Protection conditions (either suffices)**

**输入：**各域和单指标异常分数，不是原始点数或原始密度。

**具体操作：**条件一：D≥.48、X<.32、M<.38、C<.45。条件二：点数异常≥.45、密度异常<.30、空洞异常<.30、X<.35。任一组完整成立即保护。

**输出：**提供给D07「是否触发解剖保护」的逻辑判断定义。

**后续去向：**虚线指向D07「是否触发解剖保护」；这不是另一条会修改分数的独立处理步骤。

**例子：**“点数异常≥.45”不等于“点数≥.45”或“减少45%”，而是标准化后的点数异常分数。

实现追溯：`_score_metrics: density_only; taper_like`；SVG节点ID：`d_guard_rule`。

### D09 · 对受保护切片限制自动排除

图中文字：**Protected**

**输入：**保护标记为true，以及S₀。

**具体操作：**S取S₀和.62的较小值；.62来自内部检测器默认排除阈值.64减.02。保留保护标记，后续排除门控也检查它。

**输出：**保护后的S和标记。

**后续去向：**进入D10「施加末端减权并交出最终异常分数」。

**例子：**S₀=.80时被限制为.62；S₀=.40时仍为.40。

**容易误解的地方：**保护不是将切片修好；只是限制当前自动判定。

实现追溯：`_score_metrics`；SVG节点ID：`d_guard_yes`。

### D10 · 施加末端减权并交出最终异常分数

图中文字：**Final score and boundary status**

**输入：**保护处理后的S或未保护的S₀，以及主窗口上下文。

**具体操作：**单侧上下文总分再乘.82；双侧不乘。最终截断到0–1。

**输出：**供最终策略使用的异常总分S，同时保留域分数、保护标记、上下文和confidence。

**后续去向：**送入E01「生成内部检测器候选标签」，再由E02「第一阶段按锁定总分阈值分流」决策。

**例子：**单侧S=.50变为.41；同时仍有单侧标记，不能因为分数够高就绕过双侧排除要求。

**容易误解的地方：**单指标阶段的.72和这里总分阶段的.82是两处不同操作。

实现追溯：`_score_metrics: final_score; window_context; score_confidence`；SVG节点ID：`d_endpoint`。

## E区：两阶段筛选

### E01 · 生成内部检测器候选标签

图中文字：**Internal detector (distinct from final thresholds)**

**输入：**S、各域、单指标异常，以及双侧/保护状态。

**具体操作：**按框内条件生成内部keep/review/exclude：强表达或特定几何组合可触发候选；若缺双侧或有保护，不能从这里直接判内部exclude。

**输出：**recommendation内部标签及原因，不是最终公开final_call。

**后续去向：**与同一总分S一并送入E02「第一阶段按锁定总分阈值分流」。

**例子：**内部阈值.38/.64与最终策略.129/.700属于不同层，不能拿其中一组替代另一组。

**容易误解的地方：**此处review意味着存在值得后续处理的证据，不表示最终报告要求用户再做人工裁决。

实现追溯：`_score_metrics: recommendations`；SVG节点ID：`e_detector`。

### E02 · 第一阶段按锁定总分阈值分流

图中文字：**Stage 1: compare S**

**输入：**最终异常总分S、内部检测器标签与保护/上下文。

**具体操作：**S≤.129走保留候选；.129<S<.700进review；S≥.700还要经过直接排除门控。

**输出：**阈值区间threshold_band及第一阶段路径。

**后续去向：**低→E03「低总分直接保留候选」；中→E04「建立内部review队列」；高→E05「高总分的直接排除门控」。

**例子：**S=.50和S=.60都先进入review，随后才按.540区别细筛门槛。

**容易误解的地方：**.540不是第一阶段直接keep阈值；当前策略也不按数据集重估这三条边界。

实现追溯：`apply_high_confidence_policy`；SVG节点ID：`e_stage1`。

### E03 · 低总分直接保留候选

图中文字：**Keep candidate**

**输入：**S≤.129的切片及其上下文记录。

**具体操作：**在当前完整二元实验应用中给出保留动作，并保留内部检测器/保护等审计字段；不做第二阶段review证据门控。

**输出：**最终keep及保留理由。

**后续去向：**沿左侧线进入E10「最终保留动作」，再写F01「写出可追溯的逐片决策记录」。

**例子：**S=.10不会为了形式完整再走一次低分review。

**容易误解的地方：**这里keep不表示“独立认证健康”；当前实验作用域不生成生物学认证。

实现追溯：`apply_high_confidence_policy; _evaluate_review_tier_row`；SVG节点ID：`e_keep_candidate`。

### E04 · 建立内部review队列

图中文字：**Internal review**

**输入：**.129<S<.700的切片；此外也接收高分直接排除门控未通过的切片。

**具体操作：**收集仍需要多维/跨窗口证据判断的切片。

**输出：**待第二阶段处理的review记录。

**后续去向：**进入E06「为每一条review选择细筛分段」。

**例子：**S=.45将实际接受低分细筛，而不是一律keep-only提前返回。

实现追溯：`apply_high_confidence_policy; _evaluate_review_tier_row`；SVG节点ID：`e_middle`。

### E05 · 高总分的直接排除门控

图中文字：**Direct-exclude gate**

**输入：**S≥.700的切片。

**具体操作：**同时要求内部检测器为exclude、主窗口双侧、没有解剖保护。任一失败即降入review。

**输出：**直接exclude，或降级review及失败原因。

**后续去向：**全部通过→E11「最终排除建议」；任一失败→E04「建立内部review队列」/E06「为每一条review选择细筛分段」。

**例子：**即使S很高，只要缺乏双侧支持也不会直接排除。

**容易误解的地方：**图右侧“all pass”长线专属这条直接排除路径，不表示跳过了保护检查。

实现追溯：`apply_high_confidence_policy; _evaluate_review_tier_row`；SVG节点ID：`e_high`。

### E06 · 为每一条review选择细筛分段

图中文字：**Review score < 0.540?**

**输入：**已经进入review的切片及其主窗口总分S。

**具体操作：**S<.540进入低分细筛；S≥.540进入高分细筛。这里只选用规则，没有重新计算总分。

**输出：**当前切片使用的tier名称和参数。

**后续去向：**yes→E07「低分review的证据要求」；no→E08「高分review的证据要求」。

**例子：**S恰好=.540时进入高分段。

**容易误解的地方：**这是主窗口分段；确认窗口不再用.540把当前切片切换到另一套规则。

实现追溯：`_validate_review_tiers; _evaluate_review_tier_row`；SVG节点ID：`e_review_split`。

### E07 · 低分review的证据要求

图中文字：**Low-score review**

**输入：**.129<S<.540的review切片、四域证据和各确认窗口结果。

**具体操作：**选用至少2个支持域、最强域≥.65的规则；每个支持域自身必须≥.45。然后还要经过共用门控。

**输出：**低分段要求，不是仅凭最强域就给exclude。

**后续去向：**进入E09「执行第二阶段全部AND条件」。

**例子：**最大域=.64时，尽管可能有两个支持域，仍未达到本段最强域门槛。

**容易误解的地方：**低分门槛.65高于高分段.60：对这项证据而言，低分需要更强理由才能排除。

实现追溯：`apply_high_confidence_policy; _evaluate_review_tier_row`；SVG节点ID：`e_low_tier`。

### E08 · 高分review的证据要求

图中文字：**Higher-score review**

**输入：**S≥.540且仍处于review的切片，包括直接排除失败后降级的高分片。

**具体操作：**选用至少2个支持域、最强域≥.60的规则；继续检查所有共用条件。

**输出：**高分段规则。

**后续去向：**进入E09「执行第二阶段全部AND条件」。

**例子：**S=.60、最强域=.62，只通过了分数与最强域这两项，仍可能因某窗口不支持而保留。

**容易误解的地方：**本段没有.700上界，因为还包括降级进入review的高分片。

实现追溯：`apply_high_confidence_policy; _evaluate_review_tier_row`；SVG节点ID：`e_high_tier`。

### E09 · 执行第二阶段全部AND条件

图中文字：**AND: every required evidence condition passes**

**输入：**被选中的tier；主窗口域证据、检测器和保护；可用3/5/7确认窗口的完整详情。

**具体操作：**主窗口必须是检测器review/exclude、双侧、无保护、confidence≥.90，并满足所选域数/最强域。每个可用窗口还必须满足检测器、双侧、无保护、域数/最强域及该tier总分下限。要求支持比例100%；缺窗口详情视作不通过。

**输出：**通过/失败、逐条失败理由、窗口支持比例。

**后续去向：**全部通过→E11「最终排除建议」；任一失败→E10「最终保留动作」。

**例子：**高分段主窗口通过，但7片窗口最强域只有.58时，不能达到.60门槛，最终keep。

**容易误解的地方：**确认窗口最低总分为低段.129、高段.540；只主窗口另查confidence。窗口检查不是把图B的auto选窗重新做一遍，也不是按“多数票”通过。

实现追溯：`_evaluate_review_tier_row: primary confidence only; all-window support=1.0; upper tier bound applies to primary only`；SVG节点ID：`e_all_gates`。

### E10 · 最终保留动作

图中文字：**KEEP**

**输入：**第一阶段保留候选，或review细筛任一必要条件未通过的切片。

**具体操作：**写final_call=keep，记录来自哪条路径和为什么不能自动排除。

**输出：**公开keep标签和完整内部审计。

**后续去向：**进入F01「写出可追溯的逐片决策记录」与viewer。

**例子：**“跨窗口不稳定而保留”和“总分低而保留”最终同是keep，但审计理由不同。

**容易误解的地方：**keep代表当前证据不足以支持排除，不保证不存在缺陷；原始点不会被删除。

实现追溯：`apply_high_confidence_policy; _evaluate_review_tier_row`；SVG节点ID：`e_keep`。

### E11 · 最终排除建议

图中文字：**EXCLUDE**

**输入：**第一阶段直接门控全部通过，或第二阶段全部证据条件通过的切片。

**具体操作：**写final_call=exclude，保存直接/细筛路径及证据。

**输出：**公开exclude标签，供下游挑选输入时参考。

**后续去向：**进入F01「写出可追溯的逐片决策记录」与viewer。

**例子：**同为exclude，可分别来自高总分直接路径或低分多域稳定细筛路径。

**容易误解的地方：**不会自动删除源文件；当前实验策略的exclude也不等于病理或技术原因已经确诊。

实现追溯：`apply_high_confidence_policy; _evaluate_review_tier_row`；SVG节点ID：`e_exclude`。

## F区：审计、展示与ROI

### F01 · 写出可追溯的逐片决策记录

图中文字：**Save one audit row per original slice**

**输入：**每片原始指标、S、内部标签、两阶段路径、窗口证据及final_call。

**具体操作：**一片一行保存，记录policy和输入校验值。实验作用域保留实际二元动作，但清除独立认证结论。

**输出：**binary audit/calls CSV、策略应用JSON及后续报告需要的信息。

**后续去向：**输出到报告；按需求进入F02「是否需要共同坐标系中的比较」的独立展示路径。

**例子：**用户看到keep/exclude；研究者仍可从audit查到review分段和失败条件。

**容易误解的地方：**阈值分流、内部候选、最终动作、认证状态是不同字段。

实现追溯：`write_high_confidence_outputs; run_publish`；SVG节点ID：`f_audit`。

### F02 · 是否需要共同坐标系中的比较

图中文字：**Shared-coordinate**

**输入：**显示需求、原始坐标和已有QC结果。

**具体操作：**若需要跨片共享ROI，建立或复用展示预配准；否则直接用原始坐标展示。

**输出：**展示坐标来源的选择。

**后续去向：**no→F03「使用原始坐标展示」；yes→F04「轻量化刚性预配准」。

**例子：**只看每片全局统计时可不做预配准；要用同一个框比较邻片时需要明确共同frame。

**容易误解的地方：**这条路径不回写D/E中的评分或决策。

实现追溯：`run_preregister`；SVG节点ID：`f_prereg_request`。

### F03 · 使用原始坐标展示

图中文字：**Raw-only view**

**输入：**原始坐标及原QC结果。

**具体操作：**直接绘制原始点，不添加共同参考变换。

**输出：**原始坐标下的证据视图。

**后续去向：**进入F08「生成现有多面板证据报告」；不据此声称可做共同解剖位置的ROI比较。

**例子：**独立旋转过的两片即使坐标数值范围相同，也不意味着图中同一位置是同一组织。

实现追溯：`slice_preregistration.py; slice_quality_visualization.py`；SVG节点ID：`f_raw_only`。

### F04 · 轻量化刚性预配准

图中文字：**Display-only rigid preregistration**

**输入：**同一个数据集内有序原始x/y、固定配置、可选显式注释排名条件。

**具体操作：**每片确定性抽样最多1000点，24个角度起始，每个最多50迭代，以较近80%对应点拟合平移/旋转。相邻变换正确组合到该数据集中间片参考系。

**输出：**每片原始→展示矩阵T、参考片、逐对关系、抽样和状态；将T应用到全部原始点产生独立展示坐标。

**后续去向：**进入F05「检查拟合失败、方向歧义和参考链状态」。

**例子：**若B已映到参考A，C先映到B，则C到A用T(B→A)×H(C→B)，不能只显示C对B的局部坐标。

**容易误解的地方：**不缩放、不镜像、不非刚性拉伸；拟合最少20点与A区QC几何配置是不同参数。已有缓存可复用，不必每次重拟合。

实现追溯：`slice_preregistration.py; slice_quality_preregistration.py`；SVG节点ID：`f_rigid`。

### F05 · 检查拟合失败、方向歧义和参考链状态

图中文字：**Fit / reference chain**

**输入：**拟合矩阵、几何残差、替代角度结果、可选注释支持和上游参考链。

**具体操作：**检查是否报错、不同方向解是否接近、几何/注释差异是否过大，以及父级链是否已有警告。当前启发式如替代方向代价比<1.05或归一化几何残差>.08可触发警告。

**输出：**estimated、warning或failed等状态，以及警告原因和受影响切片。

**后续去向：**有失败/歧义→F06「把不可靠预配准显式显示出来」；获得拟合且无记录警告→F07「保存已估计的展示坐标」。

**例子：**两个明显不同旋转方向的拟合代价很接近时，要提示方向歧义。

**容易误解的地方：**图上“reliable enough”是状态/启发式检查的概括，不是经过真值验证的解剖准确率。

实现追溯：`slice_preregistration.py: failure / ambiguity warnings propagate along composed chain`；SVG节点ID：`f_fit_status`。

### F06 · 把不可靠预配准显式显示出来

图中文字：**Uncertain / failed**

**输入：**配准失败、歧义或受警告参考链影响的切片。

**具体操作：**保留失败和传播状态；显示能提供的坐标及警告，说明局部比较受限，不静默改为成功。

**输出：**带可见限制的展示状态。

**后续去向：**进入F08「生成现有多面板证据报告」；用户解读ROI时必须同时看到警告。

**例子：**若相邻配准边不可靠，经该边组合到参考系的后续片也应保留相关警告。

**容易误解的地方：**配准误差不直接变成切片QC的低质量证据。

实现追溯：`slice_preregistration.py; slice_quality_visualization.py`；SVG节点ID：`f_warn`。

### F07 · 保存已估计的展示坐标

图中文字：**Fitted coordinates**

**输入：**合法刚性矩阵、有效参考链且没有触发当前警告的拟合。

**具体操作：**保存矩阵和逆矩阵、展示坐标、身份映射、参数和哈希。

**输出：**共同frame中的点及原始对应关系。

**后续去向：**进入F08「生成现有多面板证据报告」。

**例子：**原始点[10,20]经T变成展示点[12,25]，仍保留原始点身份与原始坐标。

**容易误解的地方：**estimated只是算法完成估计；无警告不证明解剖对应完全正确。

实现追溯：`slice_preregistration.py; slice_quality_visualization.py`；SVG节点ID：`f_fit_ok`。

### F08 · 生成现有多面板证据报告

图中文字：**Current viewer: KDE • capture • components • statistics • binary calls**

**输入：**二元决策、原始指标、点级表达、KDE/成分证据，以及可选的展示坐标和状态。

**具体操作：**组织Overview、Statistics、Slice evidence、All slices、Methods页面，联动3/5片窗口及KDE、表达捕获、成分图。

**输出：**可检查的HTML报告或多数据集集合；每片显示QC结论、证据与坐标来源。

**后续去向：**共享坐标可用时进入F09「准确框选并追溯原始点」；原始视图仍可独立检查。

**例子：**KDE图颜色表示局部点密度估计，表达图颜色表示捕获/基因信号；二者不是最终总分热图。

**容易误解的地方：**显示3/5片的窗口不等于QC主窗口或3/5/7确认窗口；颜色和视图缩放不修改final_call。

实现追溯：`slice_quality_visualization.py: render_binary_slice_quality_appendix; raw/display toggle; linked 3/5 slice windows`；SVG节点ID：`f_viewer`。

### F09 · 准确框选并追溯原始点

图中文字：**ROI: display rectangle → exact selected points → inverse raw polygon**

**输入：**指定frame_id中的展示矩形、邻片的原始→展示矩阵和点身份。

**具体操作：**将点映到展示frame后做矩形包含判断；把矩形四角经逆变换映回原始坐标，得到多边形。浏览器导出抽样选点，服务器export-roi可校验哈希后在全点缓存重放。

**输出：**每片选中的原始行号/obs身份、坐标、计数、frame_id和原始ROI多边形。

**后续去向：**交付可追溯选区；它不回到D/E重新改变QC。

**例子：**旋转后的展示矩形在原始坐标里是斜四边形，不能用其轴对齐外接框代替精确选区。

**容易误解的地方：**相同frame范围不保证完全相同的解剖区域；抽样点数量也不等于全量ROI点数量。

实现追溯：`slice_quality_detail_roi.js; export-roi: frame_id, source_row, obs_name, full-cache hashes; never use raw axis-aligned bounding box as exact inverse`；SVG节点ID：`f_roi`。
