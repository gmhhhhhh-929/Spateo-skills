# Spateo Referee：切片质量筛选与可追溯展示

Spateo Referee 在正式配准前，依据连续切片中的表达与形态异常，筛选可能存在技术缺陷的切片。当前框架为“原始指标 → 多域评分路线与双侧组织损失路线并行 → 二元结论 → 交互报告”。公开状态为 **retain / exclude**。引擎中的 `keep` 是 retain 的兼容字段值，表示证据不足以支持自动排除，并不证明组织完整；`exclude` 不是对实验原因的诊断。内部 `review` 仅是多域路线的细筛队列。

当前发布的是 **tissue-loss v3 实验策略**，使用 [tissue_loss_v3.json](../policies/tissue_loss_v3.json)。历史 joint-review v2 保留为兼容评分路线及消融对照；旧的验证数字不能作为 v3 的验证结果。必须使用 `experimental_policy` 应用范围，报告不生成生物学认证。以下先解释 v3 新增路线，再记录保留的多域计算与历史验证来源。

阅读顺序：输入与术语 → 评分 → 阈值分支 → 参数来源 → 实验依据 → 展示与复现。

[完整总流程图（SVG）](workflow.svg)展开信号可用性、滑动窗口边界、两条决策路线与限定保护；覆盖预配准、失败、viewer 和 ROI。可维护图源为 [build_workflow.py](build_workflow.py)，从实际 [policy JSON](../policies/tissue_loss_v3.json)读取阈值。修改策略后运行 `python references/build_workflow.py` 更新图。

## v3：双侧组织损失与捕获损失路线

**为什么不能只看总分或表达是否正常？** 删除大量细胞位置后，剩余组织仍可能致密，残余细胞表达也可能正常。点数、面积和密度变化都属于几何域，强求第二个异常域会错过纯组织缺失。v3 因此检查原始组织量与覆盖指标，不把这些相关指标伪称为统计独立证据。

对每个可用 3/5/7 切片窗口，排除焦点片，分别计算左、右邻片的指标中位数。双侧保守参照与缺失比例定义为：

```
reference = min(median(left), median(right))
deficit = max(0, 1 - observed / reference)
```

参照必须在两侧均有有限正值；几何路线还要求点数参照达到配置的最低点数（默认20）。使用较低一侧，要求焦点片同时低于前、后局部参照；平滑的单调收窄本身不会构成双侧骤降。此处的 deficit 是**相对于邻片的观测缺失**，不是已知真值，也不等于模拟注入比例。

| 路线 | 主窗口候选条件 | 适用证据 |
|---|---|---|
| 几何组织损失 | 点数缺失 ≥50%，且面积缺失 ≥35% **或** 密度缺失 ≥35% | 边缘截断常损失面积；随机缺失、内部空洞、条带撕裂常损失密度。无需表达同时下降 |
| 捕获损失 | 每点计数中位数缺失 ≥50%，且检出基因中位数缺失 ≥30% | 必须显式 `capture_loss_evidence_available=True`；归一化代理、one-hot 或来源不明不能通过 |

这些是机制驱动的冻结经验门槛，不是已证实最优值，也不是“50%注入必然检出”的保证。每条路线须在**主窗口通过**，并在可用确认窗口中至少 `min(loss_min_confirming_windows, available_windows)` 个窗口通过；当前策略 `loss_min_confirming_windows=2`。与主窗口同宽的确认项计入这个总数：例如主窗口为3且3/5/7均可用，3通过后还须5或7至少一个通过，不是另加两个窗口。没有有效确认窗口不能通过。完整窗口详情和未通过原因保留在审计中。

最终排除是“原有多域路线通过 **或** v3 损失路线通过”。新增路线不受旧总分 K/E、两个支持域、旧检测器候选标签的限制。因此较低总分也可能合法排除；必须展示它实际通过的是组织损失路线，不能再解释为总分跨过 .700。

### 解剖保护只保护什么

v3 不再把“几何异常但表达正常”单独视为保护理由。只有原本看似几何异常的片，同时满足**实际点数和面积均位于前、后紧邻片之间**，并且分子/损伤/连续性无强异常、无独立组织或捕获损失证据，才启用局部解剖过渡保护。它保护的是平滑的组织量与覆盖范围过渡，不是低分、致密残片或任意小组织。末端缺少双侧参照属于证据不足，不应宣传为已确认自然解剖。

### 可用性与运行模式

`SliceQCConfig(tissue_loss_enabled=True)` 默认提取 `loss_evidence_version='bilateral-v3'` 的独立缺失证据；False 用于明确标记的旧算法重放。最终策略需 `enable_tissue_loss_resolver=True`。修改策略 JSON 但不重新提取/重算缺失证据，不构成 v3 QC。旧缓存缺少实测捕获语义时，不可根据有限数值猜测可用；可进行声明受限的几何重评分，但不伪造捕获依据。

主窗口和每个确认窗口的 `loss_evidence_config` 必须与策略中的冻结参数一致；旧参数缓存不能配新参数标签直接发布。CLI 的 v3 实验发布需显式 `--allow-unvalidated-policy --application-scope experimental_policy`。默认不绕过验证；该标志只是同意使用未独立验证的开发策略，不把任何 validation 标记改成 true。仅展示既有完整审计时，可不传 `--policy`。

关键审计字段为 `tissue_loss_exclusion_gate`、`tissue_loss_route`、`tissue_loss_reason`、`tissue_loss_window_support`，以及逐窗口 `geometry_loss_candidate` / `capture_loss_candidate` 和双侧 deficit。viewer 直接读取这些记录，不在浏览器重做科学判断。

### 能力边界与验证口径

双侧法无法保证发现端点损失、全序列共同降质、长连续坏片相互掩盖、观测量与邻片天然差异很大的组织。严重缺失也可能因参照缺失而无法自动排除；不能声称所有类型、所有程度都能检出。没有专家真值的真实数据只能报告排除数量与证据，不称为准确率。

v3 的新测试结果以对应运行的冻结代码/配置、逐试验最终动作、分缺陷与剂量汇总为准。**检出率 = 已知注入缺陷中最终 exclude 数 / 合格注入数**；review+exclude 是初筛候选率，不能替代最终检出率。合成缺陷检出不等于真实组织缺陷准确率。保留控制、天然收窄与边界等负例，报告误排和漏检；不能为了达到目标百分比隐藏失败样本。

## 输入、坐标和指标

输入可以是一个包含多张切片的 H5AD、以离散 z 表示切片的 H5AD，或每片一个 H5AD 的目录。明确选择切片字段、顺序、原始坐标键、表达层、细胞身份和可用注释。目录默认自然文件名排序；实际顺序不同时用含 `path,order` 的 manifest。不同样本、物种或时期分开计算邻域。数字切片编号不自动等于物理距离；缺号不能直接指控相邻切片低质量。

- **原始坐标**：输入所选坐标，用于全部 QC 指标，不覆盖。
- **展示预配准坐标**：由原始坐标经刚性变换得到，仅服务共同视野与 ROI。
- **正式配准坐标**：下游独立分析；展示预配准不替代它。
- **异常总分 S**：0–1 的综合异常指数，越高代表异常证据越强；不是缺陷概率。
- **证据域**：密度/组织量、表达捕获、损伤代理、连续性四类异常。它们共享部分指标，不能当成统计独立的证据。
- **邻域支持字段（score_confidence）**：当前实现双侧为 1、单侧为 0.72；0.90 的门槛主要排除单侧，不是“90% 正确概率”。

| 证据域 | 测量内容与用途 | 解读限制 |
|---|---|---|
| Density / amount | 点数、凸包面积内密度、空洞、近邻距离尾部、组织碎片、最大连通成分占比 | 小组织或末端切片不自动意味着缺陷；单位与采样平台影响绝对值 |
| Expression capture | 每点计数/检出基因的中位数、零值比例、复杂度、检出基因比例、局部低捕获比例及聚集 | 捕获计数不是原始测序深度；注释 one-hot 不属于表达 |
| Damage proxies | 线粒体比例和组织碎片 | 可能受应激、细胞组成、分割方式影响，不能诊断损伤原因 |
| Cross-slice continuity | 表达概貌变化、细胞类型组成变化、空洞证据 | 需要对应测量；生物学变化也会引起异常，不能单独认作技术损坏 |

代码入口：[slice_quality.py](../runtime/spateo/preprocessing/slice_quality.py) 中的 `scan_h5ad_series`、`scan_h5ad_collection`、`_score_metrics`。选择层的行和/非零计数优先于过时 obs 汇总。声明的注释one-hot X禁用捕获证据；非计数矩阵优先使用obs汇总，否则仍计算矩阵派生代理量，必须说明限制；不能以已有配准坐标冒充未配准输入。少于2个有效坐标点或退化点集返回受限几何值；配置中的min_points_geometry=20目前未在几何计算中生效。

## 从局部参照到异常总分

主窗口默认含连续 3 片；`auto` 可比较 3/5/7。指标评分还使用最多 9 片的稳健支持趋势，以降低连续损坏邻居互相掩盖的影响。局部参照排除当前片，有双侧邻居时用两两斜率中位数建立趋势；只有单侧时用邻居中位数。详见 `_local_expected`、`_score_metrics`。

下降型指标使用相对下降 `(expected-observed)/abs(expected)`；上升型指标使用绝对增加 `observed-expected`。`_metric_anomaly` 将效应大小映射到轻/重异常区间，并与稳健残差分数取最大值。稳健尺度优先 `1.4826×MAD`，退化时回退标准差，再退化为 1。残差 z 分数从 1.5 起、跨度 3 映射到 0–1；上升型近零指标另乘最小效应约束，避免微小变化被极小方差放大。双侧参照不一致的惩罚为 `exp(-disagreement/(2.5×global_scale))`，截断至 0.35–1；单侧指标乘 0.72。

密度域和表达域取可用指标加权均值与 `0.65×最强指标+0.35×次强指标` 的较大值。损伤与连续性使用可用指标加权。缺失测量不能解释为正常；内部零异常填充值只是未获得证据。权重和细节见 `_weighted_available`、`_top_two_evidence`、`_score_metrics`。

未施加保护前：

```
weighted = .31*density + .39*expression + .12*damage + .18*continuity
S_raw = max(weighted, clip(.48 + .78*(max_domain - .68), 0, 1))
```

**旧版保护候选**有两个分支（仅用于说明 v2 兼容评分，不代表 v3 最终保护）：

1. 仅密度明显异常：density≥.48、expression<.32、damage<.38、continuity<.45。
2. 类似自然收窄：点数异常≥.45、密度异常<.30、空洞异常<.30、expression<.35。

v2 任一命中即可截分并阻止排除，正是部分漏检来源。v3 还必须通过上文的实际点数/面积平滑过渡、正常分子与连续性、无独立损失检查后才保护。确认保护后总分上限仍为检测器排除阈值减 .02（默认 .62）；单侧末端总分再乘 .82。

内部检测器的 `review=.38 / exclude=.64` 与最终策略的 `.129/.700` 是不同层。内部 exclude 需要双侧且无保护，并满足“总分≥.64 且至少两个强域”，或“表达域≥.78”，或“密度≥.82、空洞≥.55、连续性≥.42”。否则总分≥.38、任一域≥.45、任一严重域≥.78、任一指标≥.75 或命中保护均可产生内部 review；其余为内部 keep。最终排除必须继续过下面的策略，不能直接采用内部标签。

## 保留的多域路线：每个总分区间实际做什么

下表只描述多域路线。v3 的双侧损失路线并行评估全部切片，可独立产生排除；不能把表中的低分 keep 当作新增路线的提前返回。

| 总分与条件 | 第一阶段 | 第二阶段 | 最终动作 |
|---|---|---|---|
| S≤.129 | 保留候选；记录检测器与保护等一致性 | 不进入细筛 | keep；不证明无缺陷 |
| .129<S<.540 | review | **实际执行全部低分域/邻域/窗口检查** | 全通过才 exclude，否则 keep |
| .540≤S<.700 | review | 实际执行全部高分域/邻域/窗口检查 | 全通过才 exclude，否则 keep |
| S≥.700，检测器 exclude、双侧、无保护 | 直接排除候选通过 | 不再重复细筛 | exclude |
| S≥.700，直接门控失败 | 降入 review | 使用高分细筛规则；原有失败条件不会被绕过 | 全通过才 exclude，否则 keep |
| 非有限总分/无法获得充分证据 | 不能得到有效排除依据 | 记录诊断，不能伪造通过 | 保守 keep，并保留异常说明 |

对每一条 review，仅按主窗口总分选择一次分段：

| 排除条件（必须全部通过） | 低分段 .129<S<.540 | 高分段 S≥.540 的 review |
|---|---|---|
| 检测器支持 | review 或 exclude | 相同 |
| 双侧邻域、无解剖保护 | 必须 | 相同 |
| 支持域数量（域分数≥.45） | ≥2 | ≥2 |
| 最强异常域 | **≥.65** | **≥.60** |
| score_confidence | ≥.90 | ≥.90 |
| 窗口确认 | 所有可用 3/5/7 窗口通过 | 相同 |
| 窗口最低总分 | ≥.129 | ≥.540 |

窗口确认逐窗检查检测器、双侧、保护、支持域数量、最强域和最低总分；窗口不需要仍落在主窗口分段的上界内。确认窗口不另检 confidence，双侧条件本身已要求相应支持。没有窗口详情则不能通过。窗口支持比例必须为 1.0。失败条件、分段、窗口详情、最终动作均写入审计。代码：`_validate_review_tiers`、`_evaluate_review_tier_row`、`apply_high_confidence_policy`。

**为什么低分也细筛？** 总分可能稀释局部或跨域异常；细筛检查异常由哪些域支持、是否跨窗口存在。旧 keep-only 路径在整个低分段提前返回，没有执行这些排除证据检查；本版本两个分段共用同一个完整评价函数。第二阶段因此不再是把低分机械重标为 keep。

**为什么原来的 .70/.80 不合适？** 若其他条件相同，`.70` 比 `.80` 更容易达到，意味着低分段更容易被排除、保留反而更苛刻。单凭低分可能漏检不能论证这种门槛倒置。新候选联合比较两个分段，低分 `.65` 高于高分 `.60`：低分需要更强域证据才能排除。注意完整规则还含不同的总分下限，不能用单个数字声称两组任意切片的总体排除概率存在严格排序。

**是否按数据集自适应？** 没有。当前 K、E、.540、.65、.60 均在此策略版本中冻结，所有应用数据集相同。局部参照与可选窗口选择可以适应数据。尚未证实重新估计 .540 本身有收益，因此没有把未经证实的“自适应阈值”作为既有功能。

## 历史 v2 实验证据（不能充当 v3 验证）

联合校准复用 20 组数据的 19,910 条指标扰动记录（10,046 缺陷、9,864 对照），比较 **45 个参数组合**。低分支持域候选为2/3，最强域候选 .60/.65/.70/.75/.80；高分候选 .50/.55/.60/.65/.70/.75/.80，并仅保留低分域证据门槛不低于高分且至少一项更高的组合。其他门控固定。选择标准：观察到零误排、不丢失基线正确检出、最大化新增缺陷检出；同分选择更高门槛。选中低 `.65`、高 `.60`、均2域。校准正确检出 6462→6721，新增259。

随后冻结参数，使用没有参加本次参数选择的 **10 组完整系列**，执行 **3 轮种子**（202609124/125/126），每组每轮 **100 个扰动计划**，共 **3,000 个计划**。计划可能影响多张切片，故不等于样本数。最终评估包含 **10,490 个缺陷目标、10,490 个对照目标**：正确自动排除 6611→6849，召回率 **63.0219%→65.2908%**，新增238、丢失0、观察到误排0；生成用时392.108秒。45组候选不是45轮实验；重复扰动不是独立生物学重复。

逐数据集和汇总结果见 [validation 数据](../provenance/validation.json) 和 [逐数据集表](../provenance/evaluation_by_dataset.csv)。冻结对象哈希在 policy 的 benchmark_summary 中记录。完整原始实验包保留在开发运行目录 `joint_review_20260912`，不作为运行 skill 的必要脚本发布。

**限制：** 这些是指标层扰动，未修改原始表达矩阵生成独立缺陷；留出仅针对本次参数选择，这些数据曾用于历史项目开发；对照来自检测器 keep，存在选择偏倚；相邻切片与重复扰动相关。零观察误排不等于真实误排率为零，试验级 Wilson 上界不是生物学误差保证。新策略仍漏检约34.7%的模拟缺陷，不能宣称已解决所有缺陷检出问题。

旧策略低检出率至少有一个可确定的结构性原因：最强域≥.80 代入现有总分式，即使仅靠最大域支路也有 S≥.5736，因此单纯降低 .540 下限不会释放低分排除。新策略同时检验两段证据门槛，而非只改分流数字。弱异常、多域支持不足、窗口不一致、保护或端点仍会使缺陷被保留；其贡献须根据逐目标审计区分，不能仅凭总体召回率归因。

## 预配准、viewer 与 ROI

使用原始点的确定性下采样拟合二维刚性变换；最近邻对应、截尾和角度初始化服务计算稳定性，不修改组织形状。默认中间片作为每个数据集自己的参考。使用列向量表示：`T_child_to_ref = T_parent_to_ref @ H_child_to_parent`。保存逐边矩阵、组合矩阵、逆矩阵、参数、随机种子、参考链、失败及歧义。无法可靠对齐的边及受影响链会显示警告；没有“配准成功即QC通过”的路径。实现：[slice_preregistration.py](../runtime/spateo/preprocessing/slice_preregistration.py)。

最终页面继续使用 [slice_quality_visualization.py](../scripts/slice_quality_visualization.py) 的 `render-detail`：Overview、Statistics、Slice evidence、All slices、Methods，联动 KDE、表达捕获、连通成分面板，支持原始/展示坐标切换及3/5片窗口。`slice_quality_report.py` 仍是集合页和旧诊断接口依赖，不另建平行 viewer。

ROI 属于一个明确的 `frame_id`。精确选区是展示点落在矩形内部；映射回原始坐标时逆变换矩形四角得到多边形，不能用原始坐标轴对齐外接框代替。导出保留 slice ID、原始行号、obs 身份、原始/展示坐标及多边形。浏览器只显示抽样点；`export-roi` 在全部点缓存上重放并验证哈希。相同展示范围不保证相同解剖区域。
