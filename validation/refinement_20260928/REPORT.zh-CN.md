# 7dpa1 → 10dpa1 本地修订验证（2026-09-28）

本次使用用户指定的本地 H5AD 和既有 conda 环境。原始数据未修改；所有实验与修正流程保存在独立目录。旧服务器不可达不再构成本次测试依赖。

## 配准诊断与同输入对照

两份本地原始 H5AD 的 SHA256 与原服务器测试输入完全相同。为分离代码版本和环境差异，旧版与新版使用相同表达归一化、相同 2,000 个参考细胞 ID、相同配准参数；并在旧 conda 环境额外运行一次当前配准代码。旧 Dynamo 随机采样器返回的参考 ID 也与原生采样一致。

7dpa 的对应背腹指标为 +78.335；10dpa 原坐标为 +50.884。默认初始化后变负。原配准变换 det≈+1，属于绕长轴约 180° 的旋转，不是镜像反射，因此禁用 allow_flip 不能解决它。关闭 nn_init 后，2,000 与 4,000 参考细胞均保持一致背腹顺序。4,000 注释引导方案用作本次完整重算。

旧版与新版刚性坐标 RMSE=0.004721；同一旧环境下换新版代码 RMSE=0.005234。该差异远小于原 CNS 错位，不能归因为移除 Dynamo 后配准显著改变。核心 morpho_alignment.py / morpho_class.py 完全相同；源码及环境差异保存在 alignment_source_comparison.json 和各 benchmark 的 comparison.json。

全胚胎 NN 更小的默认结果反而解剖方向错误，说明不能只优化整体重合度。修正后 CNS 仍有生长与局部差异；4,000 方案 target→source CNS 距离 p95 约 197，不能声称逐细胞准确重合。保留 SN-S 刚性输出，未为了好看使用非刚性压缩消除真实生长。Z 背腹顺序仅是这组具有对应注释和坐标方向的数据的检查线索，不适用于任意输入。

## nn_init 与 PCA

近邻初始化在粗体素的表达表征中找候选配对（本次是表达矩阵和 KL 距离），然后估计刚性变换；并在后续优化中保留近邻引导。它本身不是 PCA。nn_init=False 跳过该粗变换及其引导，坐标预处理和正式配准仍执行。它是可选的姿态假设，不能把本次关闭设置推广成所有样本的默认规则。

两个拟合场的逐点方向余弦中位数 0.995331，但长度比并不恒定。旧算法使用高斯/均匀混合模型 EM、速度加权控制点及 lambda*sigma²*K 正则；新算法使用空间控制点、Huber IRLS 与 lambda*I 岭正则。不能把旧版 1e4/1e5 glyph factor 或 5e4 轨迹积分时间直接复制到新版，也不能把这个数据集的长度比当作通用换算因子。旧 wrapper 的方向相似性验收不能保证拟合幅值正确。本地旧环境本身存在 nbformat/numpy 包版本约束冲突，已记录；实际配准和场拟合均成功，但不将它宣称为无冲突的生产环境。

新版 viewer 用点云尺度和拟合向量 q95 确定可见箭头长度，滑块只改变显示几何；保存的科学向量保持原值。mapping 箭头在 ×1 时落到真实选中的目标细胞坐标。模型时间不是天，输入坐标没有独立物理校准。

## 界面和解释

- 沿用 3D 重建 viewer 的深色界面、紧凑顶部导航和分组侧栏；时间点颜色固定为粉/蓝。
- 配准提供共享坐标范围和同步相机分屏、叠加、前后对照；透明度独立控制；可切换旧/新默认对照。
- 向量使用实心箭头；轨迹使用模型时间渐变与方向箭头，预测路径不冒充观测细胞。
- feature 同时显示于源细胞和其方向轨迹；路径颜色是种子细胞的 feature 值，沿路径恒定，不冒充沿途重新计算的值。
- 基因图默认对数显示（log1p），表达点、真实拟合均值和置信区间一起变换；保留线性显示。无效拟合区间显示缺口而非 0。
- GLM q 表示非线性关联的显著性；Spearman rho 表示单调关系强度。|rho|≥0.3 是探索性的展示阈值，不是统一生物学标准；FDR 与效应量分别展示。
- 本轮沿用 48 基因候选验证面板，共 7 个 feature/336 次 GLM，不是全基因组筛选。支持配置 glm_genes="*" 进行独立全基因组运行。单个样本/时期和空间相关性限制生物推断；不解释为因果或真实细胞谱系。

## 最终结果与检验

完整科学 run `local_anatomy_refined_v2` 已完成；后续 `local_anatomy_refined_viewer_v4` 校验并复用所有科学阶段，仅重建 viewer。独立验证通过所有输出 SHA256、原始 counts/坐标不变、完整细胞 ID、mapping 端点、轨迹种子及首点、时间单调性、有限 feature、Jacobian trace 与 divergence 一致性、336 次 GLM 状态与 q 范围。

本轮实际较强的单调关联包括 speed–SMESG000007128.1（rho≈−0.332）、speed–SMESG000026569.1（−0.314）和 curvature–SMESG000007128.1（+0.322）；均通过各自 feature 内 FDR。其余 feature 在这 48 基因中没有达到探索性的 |rho|≥0.3，尽管部分非线性 GLM 显著。这里不声称全基因组发现，也不把这些效应描述为很强。

Jacobian Frobenius–SMESG000022928.1 的 1,500 个展示点中，共有 2,998 个上下界数值不可用，均显示为 null/缺口，页面明确提示不能完整评估不确定性；拟合均值保留。其他本轮展示曲线的上下界有限。
